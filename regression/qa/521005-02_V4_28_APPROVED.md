## FACT

Direct PDF interpretation was over-classified on `26-057869` through `26-057872`: contour slopes/steps were treated as evidence for extra faces/bends, causing premature `VIEWS_ONLY`. Comparison against the supplied training/reference DXF showed that the source can be resolved more simply without violating PDF evidence.

Physical reference facts used only as regression assertions:

- `26-057867`: one bend pair, pair spacing `3.68`, full bend span `150`.
- `26-057869`: one local bend pair, pair spacing `3.68`, span `555`; part overall width is `1025`, so the bend domain is not the full bbox width.
- `26-057870`: same local-domain principle, bend span `555`, not full part width.
- `26-057871`: one proved bottom flange; reference bend pair spacing `3.68`, bend span `600`; the sloped upper contour remains in the same planar face.
- `26-057872`: same principle, bend span `600`; sloped contour is not an extra face.
- For `057871/057872`, an explicit R10 trims the physical maximum relative to the theoretical sharp intersection; physical bbox and theoretical summary dimension therefore need not be numerically identical.
- `26-058014` was still customer-confirmation-pending and is excluded from this topology approval.

## ROOT_CAUSE

`AI_TOPOLOGY_ERROR` — face creation was triggered by silhouette complexity instead of positive bend evidence. The existing FACE_GRAPH and BEND_DOMAIN rules correctly constrain already-created faces/bends, but did not explicitly prohibit creating a FACE from slope/step/contour change alone.

## PROPOSED_LESSON — APPROVED

1. `FACE_CREATION_REQUIRES_BEND_EVIDENCE`: contour direction change/slope/step/R/C is not sufficient evidence of a new face.
2. `SAME_FACE_FIRST`: test a single planar face with complex contour before splitting; split only on positive formed-transition evidence.
3. `LOCAL_BEND_DOMAIN_BEFORE_UNFOLD`: prove the actual shared-edge/material span before bend arithmetic; never expand a local flange to full bbox width.
4. `THEORETICAL_SHARP_CLOSURE_FOR_R_CONTOURS`: distinguish theoretical-sharp dimensions from R/C-trimmed physical bbox.
5. Training/reference DXF is diagnostic/audit evidence only; do not reverse-fit new geometry from it.
