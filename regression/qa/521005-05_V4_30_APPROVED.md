# 521005-05 — V4.30 APPROVED calibration regression

**Approval:** USER APPROVED / PUSH 2026-10-05.

## Scope

This regression captures only the generalizable source-reading and 90-degree bend-end relief lessons from calibration job `521005-05`. Job-specific coordinates remain regression evidence and are not reusable construction defaults.

## FACT -> ROOT_CAUSE -> PROPOSED_LESSON -> REGRESSION_CASE

### 057861 — customer-pending source value

**FACT:** the unresolved source dimension remains FLAGGED while customer confirmation is pending. A sample/reference does not silently close it.

**ROOT_CAUSE:** `AI_WORKFLOW_ERROR` when reference geometry is treated as replacement source authority.

**PROPOSED_LESSON:** keep proved geometry exact and retain `CUSTOMER_CONFIRMATION_PENDING` locally until source/user authority resolves the field.

**REGRESSION_CASE:** reference/sample presence alone must not promote the pending value to production PASS.

### 057864 — 8-R5 customer-pending family

**FACT:** the `8-R5` corner family remains customer-confirmation pending.

**ROOT_CAUSE:** `AI_RULE_MISAPPLICATION` if sample radii are used to close an unresolved source callout.

**PROPOSED_LESSON:** a sample may diagnose intent but cannot replace unresolved source authority.

**REGRESSION_CASE:** keep the R family locally FLAGGED until confirmed; do not drop already proved contour geometry.

### 057862 — same family, separate source groups

**FACT:** `2-Ø9` left, `6-Ø9`, and `2-Ø9` right are separate source groups even though they share the broad HOLE/Ø9 family. Their Y dimension graphs differ; an X chain may be continuous without making the groups one datum family.

**ROOT_CAUSE:** `AI_MISREAD` / `AI_WORKFLOW_ERROR` from collapsing same-size leaders into one feature group.

**PROPOSED_LESSON:** close each `SOURCE_FEATURE_GROUP` independently: leader/callout -> quantity -> X witnesses -> Y witnesses -> datum -> host face -> canonical members. Aggregate count is downstream only.

**REGRESSION_CASE:** total Ø9 count may match while group allocation is wrong; this must FAIL group closure.

### 057865 — false source/reference conflict

**FACT:** source `10.5 / 8.5` are inside bend dimensions. The earlier measured `10.0 / 8.0` were taken from an outside edge and therefore were not the same physical parameter.

**ROOT_CAUSE:** `AI_RULE_MISAPPLICATION`.

**PROPOSED_LESSON:** require `SAME_PHYSICAL_PARAMETER_BEFORE_REFERENCE_CONFLICT`: same code, source group, host face, physical witnesses, dimension semantics, inside/outside state, frame and units before numeric conflict comparison.

**REGRESSION_CASE:** inside-vs-outside measurements with different witnesses must not be labeled `SOURCE_CONFLICT` merely because their values differ.

### 057873 — bend-edge length and 90-degree bend-end relief

**FACT:** `248` and `50` are **chiều dài cạnh uốn / bend-edge lengths**. They are actual shared-edge material domains, not bbox-spanning bend lengths.

**FACT:** for the relevant junction, `T=2` and the main-face bend-end step is `S=+2`, so the approved 90-degree bend-end-offset mechanism requires NO SLIT.

**FACT:** supplied three-example relief DXF establishes:
- `S=-2`: slit `T+0.2=2.2` beyond the actual recessed edge; `4.2` from the zero/outside reference;
- `S=0`: slit `2.2` from the actual edge;
- positive offsets do not require this relief. The final user clarification explicitly removes the provisional `0<S<=T/2` FLAG branch: `S=+1`, `+1.5`, `+2` are NO SLIT for this mechanism.

**ROOT_CAUSE:** `AI_TOPOLOGY_ERROR` / `AI_RULE_MISAPPLICATION` when bend domains are extended to bbox or generic crossing-bend relief is applied before signed bend-end offset closure.

**PROPOSED_LESSON:** lock bend-edge length first, then apply `BEND_END_OFFSET_90`: `S>0 -> NO SLIT`; `S=0 -> T+0.2`; `S<0 -> T+0.2` from actual recessed edge, equivalent to `|S|+T+0.2` from the zero/outside reference. Scope is 90 degrees only.

**REGRESSION_CASE:** 057873 source-only reconstruction must preserve bend-edge lengths `248/50` and must not add a bend-relief slit from this mechanism at the `S=+2` junction.

## Terminology lock

- cạnh uốn = bend edge / shared bend edge
- chiều dài cạnh uốn = bend-edge length
- độ bậc tại đầu cạnh uốn = bend-end offset
- rạch thoát uốn = bend-relief slit

Do not use `bend setback` for bend-end offset.

## Non-promotion boundaries

- `248`, `50`, `10.5`, `8.5`, `8-R5`, and the individual 057862 groups are calibration evidence, not universal coordinates.
- The bend-end offset relief rule is currently approved for 90-degree junctions only.
- Existing custom source slit, BOXMET, opposite-fold `R=t`, and >90-degree relief mechanisms remain independent.
- Historical releases are immutable.
