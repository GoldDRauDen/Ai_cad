# 521001-13 — V4.24 APPROVED DATA manufacturing canonicalization regression

**Status:** USER APPROVED / PUSH 2026-10-01  
**Release:** V4.24  
**Scope:** production-wide `PDF_DATA_RAW` execution hardening. No numeric Nobi, thread-pilot, hole-capacity or Laser-R table value is changed.

## FACT

The repo already contained customer-DATA geometry authority, M* pilot conversion, material/thickness automatic Laser R, and the general `Delta >= 0.1 mm` DATA<->PDF flag gate. The gap was their interaction:
- `DATA 100%` could be misapplied as raw-copy output, omitting required automatic R.
- A tap DATA cluster may contain both a nominal thread-size reference and an inner/raw pre-hole; those roles were not explicitly separated.
- The user clarified M6 was only an example: the mechanism applies to **every `M*`**.

## ROOT_CAUSE

`AI_RULE_MISAPPLICATION / AI_WORKFLOW_ERROR`.

## PROPOSED_LESSON — APPROVED

### DATA_MANUFACTURING_CANONICALIZATION
DATA remains the 100% source geometry/provenance authority. Active manufacturing rules still control their scoped production parameters; each intentional change is recorded canonicalization, not arbitrary redraw.

### DATA_AUTO_R_CANONICALIZATION
For every otherwise uncalled eligible **outside corner <=90°**, apply the active material/thickness automatic Laser R even when customer DATA is sharp. Explicit source R/C wins at the same corner.

### DATA_TAP_NOMINAL_VALIDATION — every M*
For a proved PDF/source `M<n>`:
1. If DATA contains an identifiable nominal thread reference for that same tap, classify it `THREAD_NOMINAL_REFERENCE`.
2. Compare `D_DATA_NOMINAL` against nominal `n`, not against the pilot/pre-hole.
3. `Delta < 0.1 mm` passes; `Delta >= 0.1 mm` -> `DATA_PDF_DIM_DIFF`.
4. `THREAD_NOMINAL_REFERENCE` is non-cut semantic evidence.
5. Inner/raw pre-hole is `THREAD_PREHOLE_SOURCE`; preserve provenance but final production CUT uses `THREAD_PILOT_TABLE.md` unless the PDF explicitly overrides effective cut diameter.
6. Exactly one pilot CUT remains per tap after canonicalization.
7. Example only: PDF M6 + DATA nominal Ø6 + raw inner Ø5.1 -> one final Ø5.0 pilot. M6 is not a special case.

## NEGATIVE REGRESSION
FAIL if:
- an eligible <=90° outside corner remains sharp solely because DATA is sharp;
- auto-R overrides an explicit source R/C;
- an M* nominal-reference becomes an extra CUT;
- raw pre-hole is compared to M nominal for the 0.1 mm gate;
- nominal-reference `Delta >= 0.1 mm` is not flagged;
- a proved M* keeps raw pre-hole instead of the approved pilot without explicit PDF override;
- nominal reference and pilot both survive as production CUT;
- M6 is treated as the only M* covered.
