# 521001-20 — V4.25 APPROVED DATA-first / manufacturing-second regression

**Status:** USER APPROVED / PUSH 2026-10-02  
**Release:** V4.25  
**Scope:** production-wide `PDF_DATA_RAW` source-preservation hardening. No numeric Nobi, thread-pilot, material-table, tolerance formula or DATA<->PDF threshold value is changed.

## FACT

The 521001-20 audit exposed a workflow boundary error rather than a new machining formula:

- Customer DXF DATA must be harvested as the geometry source before any production adjustment.
- DATA `855` and `600` legitimately become manufacturing `854.75` and `599.75` because the PDF/source tolerance rule controls those dimensions after DATA harvest.
- PDF M5 with DATA nominal-reference `Ø5` and raw pre-hole `Ø4.134` legitimately becomes one laser pilot `Ø4.2` after M5 identity is locked; the raw pre-hole is not the nominal-thread comparison parameter.
- DATA height `60.000709679` versus PDF nominal `60` is below the normal DATA<->PDF threshold. With no manufacturing rule controlling that height, snapping it to `60.000` is an unauthorized redraw.
- LINE/ARC/CIRCLE versus equivalent LWPOLYLINE/bulge may prevent AutoCAD `OVERKILL` from deleting all overlaid entities even when physical curves are identical. Entity count/type identity is therefore not the manufacturing acceptance criterion.

## ROOT_CAUSE

`AI_WORKFLOW_ERROR / AI_RULE_MISAPPLICATION`.

V4.24 correctly allowed manufacturing canonicalization, but the pipeline did not make the immutable raw-DATA stage and the exact scope of each permitted manufacturing change explicit enough. That allowed a low-delta PDF nominal to be mistaken for permission to snap unrelated DATA geometry.

## PROPOSED_LESSON — APPROVED

### DATA_RAW_FREEZE
Before tolerance, Nobi, tap-pilot, R/C or other production adjustment, harvest and freeze `RAW_DATA_SNAPSHOT`, then classify a complete `PHYSICAL_DATA_BASELINE`.

### SAME_PARAMETER_GATE_BEFORE_CANONICALIZATION
Compare DATA and PDF only when they are the same physical parameter. Normal threshold remains `Delta < 0.1 mm` pass and `Delta >= 0.1 mm` -> `DATA_PDF_DIM_DIFF`. Passing this gate does **not** by itself authorize changing DATA to the PDF nominal.

### MANUFACTURING_CHANGE_LEDGER
Every physical difference between DATA baseline and final manufacturing geometry requires an active routed rule and a local record of:

`source_members, host_face, source_geometry_or_value, same_parameter_gate_status, controlling_rule, changed_scope, canonical_geometry_or_value, serialized_members`.

Valid examples include source tolerance `855 -> 854.75`, `600 -> 599.75`, M5 pre-hole `Ø4.134 -> Ø4.2`, explicit R/C, automatic material R and proved Nobi/bend placement.

### UNTOUCHED_DATA_INVARIANCE
All DATA physical geometry outside approved `changed_scope` must remain physically identical within CAD numerical/serialization precision. The DATA<->PDF threshold is not a redraw tolerance.

### REPRESENTATION_EQUIVALENCE
Exact physical LINE/ARC/CIRCLE geometry may be serialized as equivalent LWPOLYLINE/bulge geometry, and vice versa. Compare physical curves/topology, not raw entity counts or `OVERKILL` behavior. Prefer source primitives when simpler and safer.

## NEGATIVE REGRESSION

FAIL if:
- a low-delta PDF nominal with no controlling manufacturing rule is used to snap/refit DATA geometry;
- a same-parameter `Delta >= 0.1 mm` is silently forced to PDF instead of flagged and retained locally;
- raw M* pre-hole diameter is compared against nominal thread size;
- a manufacturing change lacks a controlling rule or exceeds its recorded `changed_scope`;
- untouched endpoints, centers, radii, sweeps or curves drift because of redraw/rounding/refit;
- raw entity type/count or AutoCAD `OVERKILL` is treated as proof of physical match or mismatch.

## REGRESSION_CASE

Executable guard: `regression/tools/check_521001_20_v425.py`.

It validates release wiring, DATA freeze/ledger/invariance tokens, strict same-parameter threshold behavior, 521001-20 tolerance values, M5 nominal/pre-hole separation, thread-pilot Ø4.2, representation-neutral geometry logic, and synthetic DXF save/read-back preserving the untouched `60.000709679` height.
